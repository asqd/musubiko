# План

Прототип интерфейса (фейковые данные): https://claude.ai/artifact/Y7tMrMtSzA4UpXWRsWExas

## Hotfix flow команды

- `hotfix/<имя>` — от свежего `origin/master`;
- `hotfix/<имя>-dev` — от свежего `origin/develop`, то же имя с суффиксом `-dev`;
- исправление попадает в обе ветки, в `-dev` — через cherry-pick.

## Этап 1. Ветки — сделано

- [x] Ядро: чтение веток через `for-each-ref`, локальные и удалённые копии, не запушенное.
- [x] Статусы: слита, слита через squash/rebase, конфликт (через `merge-tree`), не слита.
- [x] Хотфиксы сравниваются со своей базой, пары рядом.
- [x] Приложение: открытие репозитория, недавние, экран «Ветки» с фильтрами и поиском.

## Этап 2. Дифф как на GitHub

- [ ] Дифф ветки от merge-base (`git diff base...branch`): дерево файлов, unified и split.
- [ ] Подсветка синтаксиса и изменённой части строки, разворот контекста.
- [ ] Отметки «Просмотрено», скрытие пробельных изменений, переименования.
- [ ] Вкладка «Коммиты»: дифф одного коммита. Вкладка «Конфликты» с предпросмотром.

## Этап 3. Hotfix flow

- [ ] «Новый hotfix»: имя из номера задачи и текста, обе ветки от свежих `origin/*`, push.
- [ ] Незакоммиченные изменения: worktree (по умолчанию) или stash и переключение.
- [ ] Перед запуском — точный список команд; выполнение по шагам, остановка на ошибке,
      «Повторить», «Откатить», «Оставить как есть».
- [ ] Проверка, что имя не занято и на `origin`; проверка доступа к `origin` до начала.
- [ ] Журнал операций с отменой.

## Этап 4. Радар хотфиксов и гигиена

- [ ] Сверка пар по patch-id: что из master-части не перенесено в `-dev`; перенос cherry-pick
      во временном worktree.
- [ ] Тревога: хотфикс в master, а в develop нет.
- [ ] «Где коммит?»: в каких ветках и тегах он есть, с учётом cherry-pick.
- [ ] Удаление слитых веток (локально и на `origin`) с возможностью вернуть.
- [ ] Checkout с выбором stash / worktree, палитра команд ⌘K.

## Потом

- Кэш статусов по паре (хэш ветки, хэш базы): в больших репозиториях (800+ веток) полный
  пересчёт сейчас занимает ~15 с.
- Фоновый `git fetch` по таймеру.
- Сборки для Windows и Linux.
- Настройки flow в репозитории (`.musubiko.toml`): имена баз, префиксы, суффикс.
