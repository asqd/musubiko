Branches, their status and hotfix flow in one window

A git client that shows which branches are already merged, even if they were squashed, and which ones will conflict. Any repository will do, even one with just main. If you use master and develop, Musubiko also makes sure every hotfix lands in both.

Download Source macOS · Windows · Linux · git 2.38+ · interface in Russian for now
status

Which branches are already merged

Musubiko compares every branch with a base: develop, master (or main) or any other branch you choose. Master, main and develop are taken from the server, so “merged” means the changes are already on the server, not just in your local copy.

  • mergedall of the branch’s commits are in the base
  • merged · squashthe commits are different, but the changes are already in the base; git branch --merged doesn’t catch these
  • conflictmerging will conflict, and you can see which files
  • not mergedthe branch has changes the base doesn’t

The merge is checked with git merge-tree --write-tree, which doesn’t touch your working copy or index. The result is cached until the branch or the base moves, so in a repository with 840 branches the list reopens in 0.1 s.

diff

Branch diffs and conflicts before you merge

The diff starts where the branch left its base, just like a pull request on GitHub. You get a file tree, unified and split views, highlighting of the changed part of each line, and a “Viewed” checkbox.

If a branch conflicts with its base, you can open the conflicts themselves and compare what the base has with what the branch has.

hotfixes

One hotfix, into master and develop

Type the task name, say “Project-4900 broken invoice totals”, and Musubiko creates two branches: hotfix/PROJECT-4900-broken-invoice-totals from a fresh master and …-dev from a fresh develop. It first checks that neither name is taken on the server, then pushes both. You can look at the commands before they run. If the repository has no develop, the hotfix is a single branch from master.

The Hotfixes page shows which fixes from master have already reached develop. A commit counts even if it was cherry-picked or squashed. If something is missing, you can carry it over from the same page.

search

Where is that commit?

Search by hash, task number or commit message. For every commit found you can see whether it is on master and develop, which tag first shipped it on master, which branches contain it and where it was cherry-picked to.

undo

You can undo anything it does

Musubiko writes every action to a journal along with how to undo it. Before undoing, it checks that nothing has changed since. For example, it won’t delete a branch that someone has committed to in the meantime, and it removes a branch from the server only with push --force-with-lease.

If you delete a branch that isn’t merged, its commits stay around: a refs/musubiko/deleted/… ref keeps them for as long as the deletion can be undone.

also
  • My branches. Only your branches. The ones with problems come first: a conflict, a base that has moved far ahead, unpushed commits, or no new commits for a week.
  • Branch cleanup. Select the branches that are merged or already gone from the server, and Musubiko deletes them both locally and on the server in a single push.
  • Checkout without stash. If you have uncommitted changes, you can open the branch in a separate folder with a worktree.
  • Command palette ⌘K. Almost everything works from the keyboard: “checkout 4888”, “diff sitemap”, a hash or a task number.
  • Plain git. Everything runs through the git CLI, so your config, hooks and credentials just work. While Musubiko is only reading, it doesn’t lock the index or get in the way of git in your terminal.
  • Error reports. A button copies the versions, the error and the log, ready to paste into a chat. Your home folder and any tokens are masked.
install

Install

Installers are on the releases page. Every platform needs git 2.38 or newer. To use a specific git, set MUSUBIKO_GIT to its path. The interface is in Russian for now.

macOSMusubiko_<version>_universal.dmg
The app is signed ad hoc, without an Apple Developer ID. On macOS 15, open it, close the warning, then click Open Anyway in System Settings → Privacy & Security. On macOS 12–14, right-click it and choose Open.
WindowsMusubiko_<version>_x64-setup.exe
SmartScreen will warn about an unknown publisher: click More info, then Run anyway. It installs for the current user, so you don’t need admin rights.
Linux.AppImage or .deb
Needs WebKitGTK 4.1 (Ubuntu 22.04+, Debian 12+).

From source

You’ll need Rust 1.88+, Node.js 20+ and, on macOS, the Xcode Command Line Tools.

git clone https://github.com/asqd/musubiko
cd musubiko
make run      # build Musubiko.app and launch it
make test     # core tests on throwaway repositories

You can get the same information in a terminal with the musubiko CLI:

cargo run -p musubiko-cli -- branches ~/work/project
cargo run -p musubiko-cli -- where PROJECT-4888 ~/work/project
